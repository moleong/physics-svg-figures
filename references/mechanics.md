## 受力與參考系

1. 逐物體列出場力及所有可能接觸；每個接觸面只先列出**可能存在的**法向力與摩擦力。
2. 法向力只在接觸受壓時存在，方向垂直接觸面並指向受力物體。
3. 光滑接觸不畫摩擦力；粗糙接觸仍須按相對運動或運動趨勢判方向，靜摩擦可以為零。
4. 繩張力沿繩並離開受力物體；理想輕繩、滑輪等假設須與題設一致。
5. 只可在明確採用非慣性參考系時加入慣性力，方向與該參考系加速度相反；不得與慣性系受力分析混寫而不聲明。
6. 核對靜止或加速條件、誰升誰降、詳解所用正方向；箭頭反向屬硬傷。

## 滑輪、繩與支承

### 相切與繞繩弧

- 用 `(cx, cy, r)` 定義圓輪，所有切點由圓心、半徑及繩方向推出。
- 豎直切線為 `x = cx ± r`，水平切線為 `y = cy ± r`；斜繩切點為圓心加 `r·n̂`。法線側由實際繞繩弧和出口方向決定，不固定取向上側。
- 繞繩弧以輪心為圓心，弧端切線方向與相鄰直繩一致。可用切線速度 `(-sinφ, cosφ)·r` 覆核。
- 接觸弧貼輪緣；其他繩段不得穿入圓內或無故脫離接觸弧。

### 定滑輪與動滑輪

- **定滑輪**：輪軸連到相對地面固定的支承。可埋入實體、接吊架或接斜撐；不得無支承懸空。
- **動滑輪**：輪軸連到負載或活動框架並隨其運動；不得強加固定於天花板的支承。
- 斜撐應可見地接到輪心／輪軸。圖層順序預設為輪盤 → 斜撐 → 輪軸點，避免白底把斜撐遮成「接到輪邊」。

### 繩與物塊連接

先保留原圖或題設的實際接點與力線。只有在本系列常見的**平動方形物塊且原圖未指定接點**時，才預設：

- 接點 = 朝滑輪方向的側面中點，即中心 + `d̂·w/2`；
- 繩不穿角點、頂面或物體內部；
- 先定物塊與接點，再由繩線、相切和出口約束反推滑輪。

若採用上述側面中點模型且繩平行斜面，繩與斜面的法向距離為 `h/2`，輪心在斜面法向 `(h/2 − r)` 處，輪緣相對角點的下垂量為 `(2r − h/2)`：

1. `h ≥ 4r`：下垂量不大於 0；
2. `h < 4r`：輪可嵌入斜面延線，但兩個穿越點之間的嵌入區必須全在角點之外。

出口側仍須驗算懸掛塊、牆及滑輪的全部非接觸淨空；這些公式只屬上述模型，不是任何繩接圖的普遍定律。

## 斜面、物塊與接觸

- 物塊若貼斜面，矩形旋轉角等於斜面角；中心 = 斜面基點 + 外側法線 × `h/2`，底面貼線。
- 標註角弧的圓心放在所標兩線交點，角弧及標籤位於正確角域；圖形實際角與定量標註一致。
- 用 `rect_line_distances(...)` 驗底邊中點垂距約為 0，並檢查四角無沉入；不要用整圖縮略目視代替。
- 用 `seg_seg_dist(...)` 驗繩、桿、擋板、彈簧及箭頭對地形的全長關係。
- **接觸區域**距離為 0，不得浮空或沉入；**非接觸區域**不得相交，視覺間隙按參考圖寬設定，預設約 2 個使用者單位。
- 懸掛物塊若題意要求對正繩，才將其中心對正繩；仍須驗證與牆、平面及滑輪的非接觸關係。

## 視覺語言與圖層

以下是課本實體重繪的**預設風格**，不是純受力簡圖的硬要求：

- 天花板、地面及物塊可用 45° `<pattern>` 剖面線，避免手寫大量稀疏短線；
- 桌面可畫厚板，斜面可畫閉合楔形，滑輪保留輪軸點；
- 多實體合成一個剪影時用單一 polygon，避免共享邊重複描邊浮現中線；
- 結構、重力、運動、張力／分量及輔助線使用 `integration-contract.md` 的語義色變數；
- 圖層安排後，檢查每個圖元的**可見終點**是否仍表達原定的連接關係。

標籤擁擠時優先整體重排，再量測；角度空間不足時可縮小角弧、移動箭頭或調整非固定物體。不得為遷就標籤而改變題設幾何。

## 力學驗收表

逐圖回答，不以固定項數代替判斷：

- [ ] 每個力都有存在條件、方向及受力物體；沒有機械式為每面補上摩擦力。
- [ ] 參考系明確，慣性力沒有與慣性系分析混淆。
- [ ] 定滑輪有固定支承；動滑輪的活動關係正確。
- [ ] 繩弧同心、直繩相切、出口方向連續。
- [ ] 接點符合原圖／題設；側面中點只在指定預設模型中使用。
- [ ] 接觸面貼合且無沉入；非接觸區域無侵入。
- [ ] 所有定量角度、長度及比例與圖形一致。
- [ ] marker 與線同色，ID 無衝突，圖層沒有改變可見語義。
- [ ] 鏡像、旋轉或複用後，所有方向已重推。
- [ ] 標籤通過 text×線及 text×text 檢查，並靠近自己的指涉物。
